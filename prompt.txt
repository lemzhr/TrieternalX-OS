1. ELF Executable Loader (Prioritas Sangat Tinggi)

Saat ini shell dan aplikasi masih menjadi bagian dari kernel.

OS modern menjalankan executable terpisah.

Contohnya:

/bin
    explorer.elf
    terminal.elf
    editor.elf
    calculator.elf

Ketika pengguna mengetik:

run explorer

kernel akan

FAT32
     ↓
baca explorer.elf
     ↓
parse ELF Header
     ↓
alokasi virtual memory
     ↓
copy section
     ↓
buat process
     ↓
switch Ring3

Tanpa ELF Loader, aplikasi belum benar-benar berdiri sendiri.
